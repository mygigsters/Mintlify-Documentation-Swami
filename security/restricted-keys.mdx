---
title: "Restricted keys"
description: "Create API keys that can only reach the modules an integration needs."
---

A restricted key is an API credential with module-level permissions. Use one for each application or integration so it can only reach the resources it needs, for example read access to Payments and no access to Customers.

## Permissions

Each permission pairs a `module` with a `permission_level`.

| Field | Values seen in examples |
|---|---|
| `module` | `Customers`, `Cards`, `Payment Intents`, `Payments`, `Workers`, `Payouts`, `Invoices`, `Subscriptions` |
| `permission_level` | `none`, `read` |

## Create a restricted key

`POST /api/v1/restricted-keys`

<CodeGroup>
```bash Request
curl -X POST https://qa-payments.mygigsters.com.au/api/v1/restricted-keys \
  -u "YOUR_UUID:YOUR_SECRET" \
  -H "X-API-Version: 1.2" \
  -H "Content-Type: application/json" \
  -d '{
  "name": "My Limited Access Key",
  "permissions": [
    { "module": "Customers", "permission_level": "none" },
    { "module": "Payments", "permission_level": "read" }
  ]
}'
```

```json Response
{
  "status": 201,
  "message": "Restricted API key created successfully.",
  "data": {
    "id": 1,
    "uuid": "810c5e37-b3f3-4a9f-bde9-1a95a5b2ce5d",
    "name": "My Limited Access Key",
    "secret_key": "NEW_SECRET_KEY"
  }
}
```
</CodeGroup>

<Warning>
  The `secret_key` is shown only once. Store it securely. It can't be retrieved or shown again.
</Warning>

## Retrieve a restricted key

`GET /api/v1/restricted-keys/{id}`

Returns the key's details and its permission for every module.

<CodeGroup>
```bash Request
curl -X GET https://qa-payments.mygigsters.com.au/api/v1/restricted-keys/1 \
```

## Update a restricted key

`PUT /api/v1/restricted-keys/{id}`

Updates the name or module permissions.

<CodeGroup>
```bash Request
curl -X PUT https://qa-payments.mygigsters.com.au/api/v1/restricted-keys/1 \
  -u "YOUR_UUID:YOUR_SECRET" \
  -H "X-API-Version: 1.2" \
  -H "Content-Type: application/json" \
  -d '{
  "name": "Updated Marketing Key",
  "permissions": [
    { "module": "Customers", "permission_level": "read" },
    { "module": "Payouts", "permission_level": "read" }
  ]
}'
```

```json Response
{
  "status": 200,
  "message": "Restricted API key updated successfully."
```

## Delete a restricted key

`DELETE /api/v1/restricted-keys/{id}`

Deletes the key immediately. Any request using it stops working straight away.

<CodeGroup>
```bash cURL
curl -X DELETE https://qa-payments.mygigsters.com.au/api/v1/restricted-keys/1 \
  -u "YOUR_UUID:YOUR_SECRET" \
  -H "X-API-Version: 1.2"
```

```java Java
    public static void main(String[] args) throws Exception {
        String credentials = Base64.getEncoder()
            .encodeToString("YOUR_UUID:YOUR_SECRET".getBytes());

        HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create("https://qa-payments.mygigsters.com.au/api/v1/restricted-keys/1"))

            .header("X-API-Version", "1.2")
            .method("DELETE", HttpRequest.BodyPublishers.noBody())
            .build();

        HttpResponse<String> response = HttpClient.newHttpClient()
            .send(request, HttpResponse.BodyHandlers.ofString());

        System.out.println(response.body());
    }
```
