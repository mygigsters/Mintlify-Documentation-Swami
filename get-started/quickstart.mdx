In this tutorial you create your first customer. By the end you'll have verified your credentials, made an authenticated call, and received a customer you can charge.

## Before you begin

Create an account in the demo (QA) environment to get your API credentials.

<Card title="Create a QA account" icon="user-plus" href="https://app-qa-payments.mygigsters.com.au/signup" horizontal>
  Sign up for the demo environment. No real money moves.
</Card>

<Steps>
  <Step title="Complete the signup form">
    After you submit, you're redirected to the login page.
  </Step>
  <Step title="Log in">
    Use the email address you registered with. When asked for a one-time passcode, enter `123456`.
  </Step>
</Steps>

<Note>
  The fixed passcode `123456` works only in the demo (QA) environment.
</Note>

## Make your first request

<Steps>
  <Step title="Get your API key">
    In the dashboard, go to **Settings → API Keys** and generate a key pair. Use a QA key for this tutorial. See [Authentication](/get-started/authentication) for details.
  </Step>
  <Step title="Create a customer">
    Customers are the people or businesses you charge. Run this from your terminal, replacing the credentials:

    <CodeGroup>
    ```bash cURL
    curl -X POST https://qa-payments.mygigsters.com.au/api/v1/customer \
      -u "YOUR_UUID:YOUR_SECRET" \
      -H "X-API-Version: 1.2" \
      -H "Content-Type: application/json" \
      -d '{
        "first_name": "Jane",
        "last_name": "Smith",
        "email": "jane.smith@example.com",
        "phone": "+61400000000"
      }'
    ```

    ```javascript Node.js
    const response = await fetch("https://qa-payments.mygigsters.com.au/api/v1/customer", {
      method: "POST",
      headers: {
        Authorization: "Basic " + Buffer.from("YOUR_UUID:YOUR_SECRET").toString("base64"),
        "X-API-Version": "1.2",
        "Content-Type": "application/json",
      },
      body: JSON.stringify({
        "first_name": "Jane",
        "last_name": "Smith",
        "email": "jane.smith@example.com",
        "phone": "+61400000000"
      }),
    });

    const data = await response.json();
    console.log(data);
    ```

    ```python Python
    import requests

    response = requests.post(
        "https://qa-payments.mygigsters.com.au/api/v1/customer",

            "X-API-Version": "1.2",
        },

            "first_name": "Jane",
    ```

    ```ruby Ruby
    require "net/http"
    require "json"
    require "uri"

    uri = URI("https://qa-payments.mygigsters.com.au/api/v1/customer")
    request = Net::HTTP::Post.new(uri)
    request.basic_auth("YOUR_UUID", "YOUR_SECRET")
    request["X-API-Version"] = "1.2"
    request["Content-Type"] = "application/json"
    request.body = <<~JSON
      {
        "first_name": "Jane",
        "last_name": "Smith",
        "email": "jane.smith@example.com",
        "phone": "+61400000000"
      }
    JSON

    response = Net::HTTP.start(uri.hostname, uri.port, use_ssl: true) do |http|
      http.request(request)
    end

    puts JSON.parse(response.body)
    ```

    ```php PHP
    <?php

    $ch = curl_init("https://qa-payments.mygigsters.com.au/api/v1/customer");

    curl_setopt_array($ch, [
        CURLOPT_RETURNTRANSFER => true,

    }
    JSON,
    ]);

    $response = curl_exec($ch);
    curl_close($ch);

    print_r(json_decode($response, true));
    ```

    ```java Java
    import java.net.URI;
    import java.net.http.HttpClient;
    import java.net.http.HttpRequest;
    import java.net.http.HttpResponse;
    import java.util.Base64;

    public class Example {
        public static void main(String[] args) throws Exception {
            String credentials = Base64.getEncoder()
                .encodeToString("YOUR_UUID:YOUR_SECRET".getBytes());

            String body = String.join("\n",
                "{",
                "  \"first_name\": \"Jane\",",
                "  \"last_name\": \"Smith\",",
                "  \"email\": \"jane.smith@example.com\",",
                "  \"phone\": \"+61400000000\"",
                "}"
            );

            HttpRequest request = HttpRequest.newBuilder()
                .uri(URI.create("https://qa-payments.mygigsters.com.au/api/v1/customer"))
                .header("Authorization", "Basic " + credentials)
                .header("X-API-Version", "1.2")
                .header("Content-Type", "application/json")
                .method("POST", HttpRequest.BodyPublishers.ofString(body))
                .build();

            HttpResponse<String> response = HttpClient.newHttpClient()
                .send(request, HttpResponse.BodyHandlers.ofString());

            System.out.println(response.body());
        }
    }
    ```

    ```go Go
    package main

    import (
    	"fmt"
    	"io"
    	"net/http"
    	"strings"
    )

    func main() {
    	body := strings.NewReader(`{
      "first_name": "Jane",
      "last_name": "Smith",
      "email": "jane.smith@example.com",
      "phone": "+61400000000"
    }`)

    	req, err := http.NewRequest("POST", "https://qa-payments.mygigsters.com.au/api/v1/customer", body)
    	if err != nil {
    		panic(err)
    	}
    	req.SetBasicAuth("YOUR_UUID", "YOUR_SECRET")
    	req.Header.Set("X-API-Version", "1.2")
    	req.Header.Set("Content-Type", "application/json")

    	res, err := http.DefaultClient.Do(req)
    	if err != nil {
    		panic(err)
    	}
    	defer res.Body.Close()

    	data, _ := io.ReadAll(res.Body)
    	fmt.Println(string(data))
    }
    ```

    ```csharp .NET

      ""first_name"": ""Jane"",
      ""last_name"": ""Smith"",
      ""email"": ""jane.smith@example.com"",
      ""phone"": ""+61400000000""
    }", Encoding.UTF8, "application/json");

    var response = await client.SendAsync(request);
    Console.WriteLine(await response.Content.ReadAsStringAsync());
    ```

  <Step title="Check the response">
    A successful request returns `201` with the new customer. Keep the `customer_id`. You use it for cards, intents, and charges.

    ```json Response
    {
      "status": 201,
      "message": "Customer created successfully",
      "my_gigster_id": "3e36d8a3-e013-4b0d-a72d-9b03c4ccb02e",
      "customer_id": "cus_hkdm99dbsh9iactpfvh",
      "save_card": "https://app-qa-payments.mygigsters.com.au/save-card/cus_hkdm99dbsh9iactpfvh/f2c1d9d2-c50d-460e-9e07-a1c58fa025f7"
    }
    ```

    The `save_card` link is where the customer can securely save a card.
  </Step>
