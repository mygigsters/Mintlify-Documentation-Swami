---
title: "Take payments with payment links"
description: "Generate a hosted payment link, send it to your customer, and track its status."
---

No integration on the payment page required: generate a hosted link, send it to your customer, and poll or listen for its status. Payment links currently support AUD only.

<Steps>

```java Java
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;
import java.util.Base64;

public class Example {
    public static void main(String[] args) throws Exception {
        String credentials = Base64.getEncoder()
            .encodeToString("YOUR_UUID:YOUR_SECRET".getBytes());

        String body = String.join("\n",
            "{",
            "  \"amount\": 250.0,",
            "  \"title\": \"Site cleanup - Bondi\",",
            "  \"description\": \"Final payment for job #8842\",",
            "  \"reference\": \"job_8842\",",
            "  \"expires_at\": \"2026-08-01T00:00:00Z\"",
            "}"
        );

        HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create("https://qa-payments.mygigsters.com.au/api/v1/create/payment-link"))
            .header("Authorization", "Basic " + credentials)
            .header("idempotency-Key", "sb184dc0-281b-4cd3-847e-d3791a84f3ab")
            .header("X-API-Version", "1.2")
            .header("Content-Type", "application/json")
            .method("POST", HttpRequest.BodyPublishers.ofString(body))
            .build();

        HttpResponse<String> response = HttpClient.newHttpClient()
            .send(request, HttpResponse.BodyHandlers.ofString());

        System.out.println(response.body());
    }
}
```

```go Go
package main

import (
	"fmt"
	"io"
	"net/http"
	"strings"
)

func main() {
	body := strings.NewReader(`{
  "amount": 250.0,
  "title": "Site cleanup - Bondi",
  "description": "Final payment for job #8842",
  "reference": "job_8842",
  "expires_at": "2026-08-01T00:00:00Z"

	req, err := http.NewRequest("POST", "https://qa-payments.mygigsters.com.au/api/v1/create/payment-link", body)
	if err != nil {
		panic(err)
	}
	req.SetBasicAuth("YOUR_UUID", "YOUR_SECRET")
	req.Header.Set("idempotency-Key", "sb184dc0-281b-4cd3-847e-d3791a84f3ab")
	req.Header.Set("X-API-Version", "1.2")
	req.Header.Set("Content-Type", "application/json")

	res, err := http.DefaultClient.Do(req)
	if err != nil {
		panic(err)
	}
	defer res.Body.Close()

	data, _ := io.ReadAll(res.Body)
	fmt.Println(string(data))
}
```

<Step title="Share the URL">

The response contains the hosted payment page `url` and the link’s `id`. Email or SMS it to your customer, or embed it in an invoice (see invoicing).

</Step>

<Step title="Track payment">

Check [Payment Link Status](/api-reference/payments/get-payment-link-status) with the link id, or subscribe to payment webhooks to be notified in real time. Once paid, use the returned `intent_id` with [Get Payment Details](/api-reference/payments/get-payment-details) for fee and settlement breakdown.

</Step>
