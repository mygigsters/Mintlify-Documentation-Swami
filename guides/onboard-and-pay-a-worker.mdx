title: "Onboard and pay out a worker"
description: "Register a worker, collect their bank details, and send a payout."
---

Register a worker, collect their bank details, then pay them. You can pay out workers in 160+ countries.

<Steps>

<Step title="Create the worker">

Register the worker with [Worker Create](/api-reference/workers/worker-create). You can include bank details up front, or add them later. Keep the returned `worker_id`.

</Step>

<Step title="Collect bank details — three options">

- **You already have them:** submit via [Add Bank Details](/api-reference/workers/add-bank-details). This takes Australian bank details.
- **Hosted form:** request a [Beneficiary URL](/api-reference/workers/beneficiary-url) and redirect the worker to a secure MyGigsters-hosted page. They enter details themselves and are returned to your `return_url`. The form shows the right fields for the worker's country.
- **Embedded form:** mount the [Beneficiary SDK](/sdks/beneficiary-sdk) directly in your web app for a fully in-context experience.

</Step>

```java Java
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;
import java.util.Base64;

public class Example {
    public static void main(String[] args) throws Exception {
        String credentials = Base64.getEncoder()
            .encodeToString("YOUR_UUID:YOUR_SECRET".getBytes());

        String body = String.join("\n",
            "{",
            "  \"worker_id\": \"wkr_1042\",",
            "  \"full_name\": \"Ravi Kumar\",",
            "  \"amount\": 320.5,",
            "  \"job_id\": \"job_8842\",",
            "  \"reference\": \"Week 27 payout\"",
            "}"
        );

        HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create("https://qa-payments.mygigsters.com.au/api/v1/worker-bank-payout"))
            .header("Authorization", "Basic " + credentials)
            .header("idempotency-Key", "mx174dc0-281b-4cd3-847e-d3791a84f3ab")
            .header("X-API-Version", "1.2")
            .header("Content-Type", "application/json")
            .method("POST", HttpRequest.BodyPublishers.ofString(body))
            .build();

        HttpResponse<String> response = HttpClient.newHttpClient()
            .send(request, HttpResponse.BodyHandlers.ofString());

        System.out.println(response.body());
    }
}
```
