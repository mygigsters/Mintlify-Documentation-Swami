---
title: "Validate member verification"
description: "Builds a Member Verification Request payload for an employee and validates it against SuperChoice **without submitting it**. Use this to check that an employee's stored details (name, DOB, address, TFN, fund identity) are..."
api: "POST https://qa-super.mygigsters.com.au/v2/mvr/validate"
---

Employer, fund, and member details are resolved server-side from the employee's stored record — you only need to supply the `employeeId`.

See the [MVR Verification](/super/guides/member-verification) guide for the full verification lifecycle.

### Request Body

<ParamField body="employeeId" type="string" required>
  The employeeId of the member to validate an MVR payload for. Employer, fund, and member details are resolved server-side from this employee's stored record.
</ParamField>

<ParamField body="employerId" type="string">
  Optional explicit employerId to use instead of auto-picking the eligible employer for the client. Use when the client has more than one onboarded-and-synced employer and there is no reliable way to auto-pick the right one.
</ParamField>

### Responses

| Code | Description |
|---|---|
| `200` | Validation successful — the payload is well-formed and was accepted by SuperChoice's validation endpoint |
| `400` | Bad request — the employee has no fund identity (usi/smsf), or no employer at the client is onboarded and synced at the clearing house |
| `401` | Unauthorized — invalid authentication credentials |
| `404` | Employee not found for this client |

import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;
import java.util.Base64;

public class Example {
    public static void main(String[] args) throws Exception {
        String credentials = Base64.getEncoder()
            .encodeToString("apiUsername:apiPassword".getBytes());

        String body = String.join("\n",
            "{",
            "  \"employeeId\": \"6a58c9406820b9ff62b527b3\"",
            "}"
        );

        HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create("https://qa-super.mygigsters.com.au/v2/mvr/validate"))
            .header("Authorization", "Basic " + credentials)
            .header("Content-Type", "application/json")
            .method("POST", HttpRequest.BodyPublishers.ofString(body))
            .build();

        HttpResponse<String> response = HttpClient.newHttpClient()
            .send(request, HttpResponse.BodyHandlers.ofString());

        System.out.println(response.body());
    }
}
