---
title: "Get Employer by ID"
description: "Retrieves a single employer record by its ID. Returns the employer's contact information, payment configuration, clearing house onboarding status, and metadata."
api: "GET https://qa-super.mygigsters.com.au/v1/employers/{id}"
---

### Use Case

- Look up a specific employer's details before submitting contributions
- Check `onboardedAtClearingHouse` to confirm the employer is ready to receive contributions
- Retrieve payment account details for reconciliation

### Request Parameters

<ParamField path="id" type="string" required>
  The employer ID
</ParamField>

### Responses

| Code | Description |
|---|---|
| `200` | Employer retrieved successfully |
| `401` | Unauthorized - Invalid authentication credentials |
| `404` | Employer not found |

### Response fields

<ResponseField name="id" type="string">
  Employer ID
</ResponseField>

<ResponseField name="name" type="string">
  Employer business name
</ResponseField>

<ResponseField name="abn" type="string">
  Australian Business Number (ABN)
</ResponseField>

<ResponseField name="contact" type="object">
  Employer contact information

  <Expandable title="properties">
    <ResponseField name="name" type="object">
      Contact person name
    </ResponseField>

    <ResponseField name="phoneNumber" type="object">
      Contact phone number
    </ResponseField>

    <ResponseField name="email" type="object">
      Contact email address
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="clientId" type="number">
  Client ID associated with this employer
</ResponseField>

<ResponseField name="superApiMeta" type="object">
  Super API metadata including payment and refund account details

  <Expandable title="properties">
    <ResponseField name="paymentDetails" type="object">
      Payment configuration for contributions
    </ResponseField>

    <ResponseField name="refundAccount" type="object">
      Bank account details for refunds
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="onboardedAtClearingHouse" type="boolean">
  Read-only status set by the system. Indicates whether this employer has been fully onboarded at the superannuation clearing house.
</ResponseField>

<ResponseField name="detailsSyncedAtClearingHouse" type="string">
  Read-only status set by the system. "NA" means no employer detail updates have been made yet, "false" means updates are pending sync to the clearing house, "true" means the latest updates have been synced.
</ResponseField>

<ResponseField name="detailsSyncedAtClearingHouseAt" type="string">
  Read-only timestamp set by the system. When the updated employer details were last synced to the clearing house.
</ResponseField>

<ResponseField name="createdAt" type="string">
  Timestamp when the employer record was created
</ResponseField>

<ResponseField name="updatedAt" type="string">
  Timestamp when the employer record was last updated
</ResponseField>
