---
title: "List Client Employers"
description: "Retrieves all employers associated with the authenticated client. Returns a list of employer records with their contact information, payment details, and metadata."
api: "GET https://qa-super.mygigsters.com.au/v1/clients/me/employers"
---

### Use Case

- Display list of employers for the client
- View employer details and payment configuration
- Manage multiple employers under a single client account

### Responses

| Code | Description |
|---|---|
| `200` | List of employers retrieved successfully |
| `401` | Unauthorized - Invalid authentication credentials |
| `404` | Client not found |
| `500` | Internal server error - An unexpected error occurred. If this persists, contact support. |

### Response fields

<ResponseField name="employers" type="array">
  List of employers associated with the authenticated client. Each employer includes contact information, payment details, and metadata.
</ResponseField>

<ResponseField name="total" type="number">
  Total number of employers associated with the client
</ResponseField>

```java Java
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;
import java.util.Base64;

public class Example {
    public static void main(String[] args) throws Exception {
        String credentials = Base64.getEncoder()
            .encodeToString("apiUsername:apiPassword".getBytes());

        HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create("https://qa-super.mygigsters.com.au/v1/clients/me/employers"))
            .header("Authorization", "Basic " + credentials)
            .method("GET", HttpRequest.BodyPublishers.noBody())
            .build();

        HttpResponse<String> response = HttpClient.newHttpClient()
            .send(request, HttpResponse.BodyHandlers.ofString());

        System.out.println(response.body());
    }
}
```
