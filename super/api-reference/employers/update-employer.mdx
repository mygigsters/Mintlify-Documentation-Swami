---
title: "Update Employer"
description: "Updates an existing employer's company, contact, address, and payment details. This is a full replace - send the complete payload, same shape as POST /v1/employers/onboard. The employer must belong to the authenticated client,..."
api: "PUT https://qa-super.mygigsters.com.au/v1/employers/{id}"
---

### Important Notes

- **Full Replace**: Validation is identical to Onboard Employer - the same required fields, the same ABN checks, and the same Direct Debit agreement requirement apply.
- **ABN Validation**: The ABN is validated in two stages - a format check (exactly 11 digits) and the ATO checksum algorithm. A syntactically-correct but non-existent ABN (e.g. 34623710897) is rejected.
- **Contact Area Code**: `contactPerson.areaCode` must be one of the valid Australian landline area codes: 02, 03, 04, 07, 08.
- **Contact Email Uniqueness**: If you change `contactPerson.emailAddress`, the new email must not already be used by another of your employers (case-insensitive), or the request is rejected with `400` (error code `4003`). Keeping the employer's current email is always allowed.
- **Ownership Check**: The employer must belong to the authenticated client. Attempting to update an employer belonging to another client returns 404.

### Use Case

- Update an employer's company, contact, address, or payment account details
- Correct or replace direct debit and refund account information

### Request Parameters

<ParamField path="id" type="string" required>
  The employer ID
</ParamField>

### Request Body

<ParamField body="companyDetails" type="object" required>
  Company and employer details
</ParamField>

<ParamField body="contactPerson" type="object" required>
  Contact person details for the employer
</ParamField>

<ParamField body="companyAddress" type="object" required>
  Company postal address
</ParamField>

<ParamField body="directDebitAccount" type="object" required>
  Bank account details for direct debit payments
</ParamField>

<ParamField body="refundAccount" type="object" required>
  Bank account details for refunds
</ParamField>

<ParamField body="directDebitAgreement" type="object" required>
  Direct debit agreement acceptance
</ParamField>

<ParamField body="legalAgreements" type="object">
  Optional. Legal agreement acceptances. All fields are required if this object is provided.
</ParamField>

<ParamField body="digitalSignature" type="string">
  Optional. Base64-encoded PNG of the employer's digital signature collected during onboarding.
</ParamField>

### Responses

| Code | Description |
|---|---|
| `200` | Employer updated successfully |
| `400` | Bad request - Missing/invalid fields, invalid ABN, Direct Debit terms not agreed, or contact email already used by another of your employers (errorCode 4003) |
| `401` | Unauthorized - Invalid authentication credentials |
| `404` | Employer not found, or does not belong to the authenticated client |
| `500` | Internal server error - Failed to update employer. |

### Response fields

<ResponseField name="employerId" type="string">
  Unique identifier for the updated employer
</ResponseField>

<ResponseField name="clientId" type="number">
  Client ID associated with this employer
</ResponseField>

<ResponseField name="message" type="string">
  Success message
</ResponseField>

<ResponseField name="onboardedAt" type="string">

</ResponseField>

</ResponseField>
