---
title: "SuperSelector"
description: "Searches for superannuation funds associated with an employee using the SuperSelector service. This endpoint matches employee details to find potential fund matches."
api: "POST https://qa-super.mygigsters.com.au/v1/verification/superselector"
---

<Tip>
  **Why it's useful:** Use it to pre-fill a freelancer's superannuation details. It finds a match at least 60% of the time. When nothing is found, the freelancer fills in their details manually.
</Tip>

### Request Payload

Send only the **employee** object with name (familyName, givenName), dob (day, month, year), and postCode.

### Response

- **matchResult**: `MATCH` when one or more funds were found for the employee, `NO_MATCH` otherwise.
- **funds**: the matched funds (fundName, fundUsi, fundAbn, memberNumber). Empty when matchResult is `NO_MATCH`.
- **transactionId**: SuperSelector transaction ID for tracking.

A `NO_MATCH` result is still a successful (200) response:

```json
{
  "matchResult": "NO_MATCH",
  "funds": [],
  "transactionId": "TXNSUPERSELECTOR1792390112358"
}
```

### Use Cases

- Fund discovery for member onboarding
- Contribution setup and fund selection
- Matching employee to existing superannuation funds

### Request Body

<ParamField body="employee" type="object" required>
</ParamField>

### Responses

| Code | Description |
|---|---|
| `200` | SuperSelector search completed. matchResult is MATCH with the matched funds, or NO_MATCH with an empty funds array. |
| `400` | Search failed - Invalid request parameters or data format. |
| `401` | Unauthorized - Invalid API credentials. |
| `500` | Internal server error. |

        );

        HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create("https://qa-super.mygigsters.com.au/v1/verification/superselector"))
            .header("Authorization", "Basic " + credentials)

            .method("POST", HttpRequest.BodyPublishers.ofString(body))
            .build();

        HttpResponse<String> response = HttpClient.newHttpClient()
            .send(request, HttpResponse.BodyHandlers.ofString());

        System.out.println(response.body());
    }
