---
title: "Get active superannuation funds"
description: "Retrieves a comprehensive list of all superannuation funds currently registered and active in the Superannuation clearing house network. These funds are verified and capable of receiving electronic contributions."
api: "GET https://qa-super.mygigsters.com.au/v1/contributions/funds/active"
---

<Tip>
  **Why it's useful:** Use it to populate a searchable drop-down of superannuation funds in your own product.
</Tip>

### Use Cases

- **Initial Setup**: Populate your system's fund dropdown/selection list
- **Periodic Refresh**: Update your local fund cache (recommended: daily)
- **Validation**: Verify a USI before attempting contribution submission
- **Member Onboarding**: Present fund options to new employees

### Response Details

The response includes each fund's:

- **USI (Unique Superannuation Identifier)**: The 14-character identifier required for contributions
- **Fund Name**: The display name for user interface purposes
- **Product Name**: The specific product name within the fund
- **Organisation Name**: The name of the superannuation organisation
- **Australian Business Number (ABN)**: The fund's ABN
- **Account Details**: Bank account information (account name, BSB, account number)
- **Contact Details**: Contact information including name, phone number, and email

### Performance

- Response is cached for 15 minutes on the server
- Average response time: &lt; 200ms
- Typical list size: 200-300 active funds

### Rate Limiting

This endpoint has a higher rate limit (300 requests/minute) as it's commonly used for autocomplete features.

### Responses

| Code | Description |
|---|---|
| `200` | Successfully retrieved the list of active superannuation funds. The response contains an array of fund objects, each with a USI and display name. |
| `400` | Bad request - The request could not be processed. This may occur if the request format is invalid or required headers are malformed. |
| `401` | Unauthorized - Authentication failed. Check that your X-Username and X-Password headers are correct and that your account is active. |
| `500` | Internal server error - An unexpected error occurred. If this persists, contact Superannuation clearing house support with your transaction ID. |

### Response fields

<ResponseField name="funds" type="array">
  Array of active superannuation funds that can receive contributions. This list is updated regularly as funds join or leave the Superannuation clearing house network.
</ResponseField>

    public static void main(String[] args) throws Exception {
        String credentials = Base64.getEncoder()

        HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create("https://qa-super.mygigsters.com.au/v1/contributions/funds/active"))

        System.out.println(response.body());
    }
