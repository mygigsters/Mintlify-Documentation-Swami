---
title: "Get Employee by ID"
description: "Retrieves employee information by UUID. Returns all static employee data stored in the database."
api: "GET https://qa-super.mygigsters.com.au/v1/employees/{employeeId}"
---

### Use Case

- Verify employee information before submitting contributions
- Retrieve employee details for display in UI
- Validate employee exists before contribution submission

### Request Parameters

<ParamField path="employeeId" type="string" required>
  Employee ID
</ParamField>

### Responses

| Code | Description |
|---|---|
| `200` | Employee retrieved successfully |
| `401` | Unauthorized - Invalid authentication credentials |
| `404` | Employee not found |

### Response fields

<ResponseField name="id" type="string">
  Employee ID
</ResponseField>

<ResponseField name="clientId" type="string">
  Client ID that this employee belongs to
</ResponseField>

<ResponseField name="email" type="string">
  Employee email address (optional)
</ResponseField>

<ResponseField name="name" type="object">
  Employee name

  <Expandable title="properties">
    <ResponseField name="firstName" type="string">
      First or given name of the fund member as registered with their superannuation fund. Must match the name on the member's fund account for successful contribution allocation.
    </ResponseField>

    <ResponseField name="lastName" type="string">
      Last name or surname of the fund member as registered with their superannuation fund. Must match exactly for the contribution to be successfully allocated.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="gender" type="string">
  Employee gender. Valid values: NOT_STATED, MALE, FEMALE, INDETERMINATE
</ResponseField>

<ResponseField name="dob" type="object">
  Date of birth. The member must be at least 18 years old. Day must be between 1 and 31.

  <Expandable title="properties">
    <ResponseField name="year" type="number">
      Birth year (4 digits). Used along with month and day to verify member identity with the fund. Members must be at least 18 years old.
    </ResponseField>

    <ResponseField name="month" type="string">
      Birth month as a full month name (uppercase). Must match the member's date of birth registered with their fund.
    </ResponseField>

    <ResponseField name="day" type="number">
      Birth day of the month. Must be between 1 and 31. Ensure this matches the fund's records for successful member identification.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="address" type="object">
  Employee address

  <Expandable title="properties">
    <ResponseField name="australianAddress" type="object">
      Australian residential address of the fund member. Used for member identification and correspondence if needed.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="taxFileNumber" type="string">
  Tax File Number (TFN)
</ResponseField>

<ResponseField name="usi" type="string">
  Unique Superannuation Identifier (USI) for the employee’s chosen super fund/product. Used when building validation and submission payloads to Superannuation clearing house.
</ResponseField>

<ResponseField name="memberNumber" type="string">
  Member number issued by the superannuation fund for this employee. Sent in the Superannuation clearing house member payload to help the fund match contributions. Must not contain blanks (e.g., ' ') or special characters. Only alphanumeric characters are allowed.
</ResponseField>

<ResponseField name="employmentPayrollNumber" type="string">
  Employment / payroll number used by the employer to identify this employee in payroll systems. Passed through as employmentPayrollNumber to Superannuation clearing house.
</ResponseField>

<ResponseField name="abn" type="string">
  Australian Business Number (ABN) for the employee (typically contractors). Stored for reference only and not sent to Superannuation clearing house APIs. Must be exactly 11 digits, numeric characters only, first digit cannot be zero. Can be presented with or without spaces (e.g., '34623710896' or '34 623 710 896').
</ResponseField>

<ResponseField name="mvrStatus" type="string">
  Latest Member Verification Request (MVR) outcome for this employee's current fund identity, if a verification has been run. One of PENDING, VERIFIED, WARNING, REJECTED, TIMED_OUT, NOT_APPLICABLE, NOT_SUPPORTED, NOT_CHECKED. Only ever set on employees created or updated through the Employees v2 endpoints — see the MVR Verification page (/mvr) for what each value means for payment eligibility.
</ResponseField>

<ResponseField name="mvrStatusReason" type="string">
  Human-readable reason or description accompanying the current mvrStatus, if any.
</ResponseField>

<ResponseField name="createdAt" type="string">
  Created timestamp
</ResponseField>

<ResponseField name="updatedAt" type="string">
  Updated timestamp
</ResponseField>

<Accordion title="Error response fields">

  Always false for error responses, indicating the operation did not succeed.

<ResponseField name="statusCode" type="integer">
  HTTP status code indicating the type of error. Common values: 400 (Bad Request), 401 (Unauthorized), 404 (Not Found), 500 (Server Error)
</ResponseField>

<ResponseField name="message" type="string">
  Human-readable error message explaining what went wrong. May include specific details about which field or value caused the error.
</ResponseField>

<ResponseField name="errorCode" type="integer">
  Superannuation clearing house-specific error code for programmatic error handling. Refer to the error code reference documentation for a complete list of codes. Common codes: 4030 (Employer not found), 4031 (Invalid ABN), 4040 (Fund not found).
</ResponseField>

</Accordion>
