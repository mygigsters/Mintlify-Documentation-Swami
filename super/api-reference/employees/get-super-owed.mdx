---
title: "Get super owed"
description: "Retrieves the total superannuation owed to an employee, broken down by employer and individual payment transactions. This endpoint is useful for providing employees with a transparent view of their super entitlements and..."
api: "GET https://qa-super.mygigsters.com.au/v1/employees/{employeeId}/super-owed"
---

### Use Case

- Display total super owed to an employee in a dashboard
- Break down super owed by employer for multi-employer scenarios
- Review individual payment transactions and their statuses
- Reconcile super payments against payroll records

### Request Parameters

<ParamField path="employeeId" type="string" required>
  Employee ID
</ParamField>

### Responses

| Code | Description |
|---|---|
| `200` | Super owed retrieved successfully |
| `400` | Bad request - invalid employee id. |
| `401` | Unauthorized - Invalid authentication credentials |
| `404` | Employee not found |

### Response fields

<ResponseField name="employeeId" type="string">
  The unique identifier of the employee
</ResponseField>

<ResponseField name="total" type="object">
  The total superannuation amount owed to the employee across all employers

  <Expandable title="properties">
    <ResponseField name="value" type="number">
      The monetary amount
    </ResponseField>

    <ResponseField name="currency" type="string">
      ISO 4217 currency code
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="byEmployer" type="array">
  Super owed broken down by each employer
</ResponseField>

<ResponseField name="payments" type="array">
  Individual payment transactions contributing to super owed
</ResponseField>
