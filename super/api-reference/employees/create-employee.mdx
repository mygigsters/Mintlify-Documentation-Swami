### Employee Data Stored

The following static information is stored:

- Name (first name, last name)
- Gender
- Date of birth
- Address
- Email
- Tax File Number (TFN)
- Superannuation identifiers (USI, memberNumber, employmentPayrollNumber)
- Optional employee ABN (if applicable)

The employee is automatically associated with the authenticated client's context.

USI, memberNumber, and employmentPayrollNumber are **required** for onboarding and are later reused when building Superannuation clearing house validation and submission payloads.

### Use Case

- Onboard a new employee using this endpoint
- Store the returned employee ID
- Use the employee ID when submitting contributions

### Request Body

<ParamField body="email" type="string" required>
  Employee email address (must be valid email format). Must be unique per client - a client cannot have two employees with the same email address.
</ParamField>

<ParamField body="name" type="object" required>
  Employee name
</ParamField>

<ParamField body="gender" type="string (NOT_STATED, MALE, FEMALE, INDETERMINATE)" required>
  Employee gender. Valid values: NOT_STATED, MALE, FEMALE, INDETERMINATE
</ParamField>

<ParamField body="dob" type="object" required>
  Date of birth. The member must be at least 18 years old. Day must be between 1 and 31.
</ParamField>

<ParamField body="address" type="object" required>
  Employee address
</ParamField>

<ParamField body="taxFileNumber" type="string" required>
  Tax File Number (TFN). Must be unique per client - no two employees under the same client can share a TFN.
</ParamField>

<ParamField body="usi" type="string" required>
  Unique Superannuation Identifier (USI) for the employee’s chosen super fund/product. This will be used when building validation and submission payloads to Superannuation clearing house.
</ParamField>

<ParamField body="memberNumber" type="string" required>
  Member number issued by the superannuation fund for this employee. This will be sent in the Superannuation clearing house member payload and used by the fund to directly match contributions to the member's account. Must be a string; cannot be blank or whitespace-only. Only alphanumeric characters, hyphens, underscores, and spaces are allowed — no other special characters. Must be unique per client - no two employees under the same client can share a member number.
</ParamField>

<ParamField body="employmentPayrollNumber" type="string" required>
  Employment / payroll number used by the employer to identify this employee in payroll systems. This will be sent as the employmentPayrollNumber field to Superannuation clearing house. Must be unique per client. If omitted, one is auto-generated and guaranteed unique.
</ParamField>

<ParamField body="abn" type="string">
  Australian Business Number (ABN) for the employee (typically contractors). Stored for reference only and **not** sent to Superannuation clearing house APIs. Must be exactly 11 digits, numeric characters only, first digit cannot be zero. Can be presented with or without spaces (e.g., '34623710896' or '34 623 710 896'). Must be unique per client - no two employees under the same client can share an ABN.
</ParamField>

### Responses

| Code | Description |
|---|---|
| `201` | Employee created successfully |
| `400` | Bad request - Invalid employee data or duplicate email (email addresses must be unique per client) |
| `401` | Unauthorized - Invalid authentication credentials |
