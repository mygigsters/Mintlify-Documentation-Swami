title: "Update employee (v2)"
description: "Identical to PUT /v1/employees/:employeeId, with one difference: changing the employee's fund identity (usi/smsf), name, gender, date of birth, address, or TFN re-triggers MVR (Member Verification) for this employee — these..."
api: "PUT https://qa-super.mygigsters.com.au/v2/employees/{employeeId}"
---

### Update Behavior

- All fields in the request body are optional
- Only provided fields will be updated
- Email uniqueness is validated per client - cannot update to an email that already exists for another employee under the same client
- `memberNumber`, `abn`, `taxFileNumber`, and `employmentPayrollNumber` are also validated for uniqueness per client on update
- Only a genuine change to a verification-relevant field (`usi`/`smsf`, `name`, `gender`, `dob`, `address`, `taxFileNumber`) re-triggers MVR — resending the same value does not

### Use Case

- Update employee super fund details (USI, member number) — this is also how you opt an existing (v1-created) employee into MVR verification
- Correct a member's name, date of birth, address, or TFN after a REJECTED verification
- Change employee address or contact information
- Modify employment/payroll number

### Request Parameters

<ParamField path="employeeId" type="string" required>
  Employee ID
</ParamField>

### Request Body

<ParamField body="email" type="string">
  Employee email address (must be valid email format). Must be unique per client - cannot match another employee's email under the same client.
</ParamField>

<ParamField body="name" type="object">
  Employee name
</ParamField>

<ParamField body="gender" type="string (NOT_STATED, MALE, FEMALE, INDETERMINATE)">
  Employee gender. Valid values: NOT_STATED, MALE, FEMALE, INDETERMINATE
</ParamField>

<ParamField body="dob" type="object">
  Date of birth. The member must be at least 18 years old. Day must be between 1 and 31.
</ParamField>

<ParamField body="address" type="object">
  Employee address
</ParamField>

<ParamField body="taxFileNumber" type="string">
  Tax File Number (TFN). Must be unique per client - cannot match another employee's TFN under the same client.
</ParamField>

<ParamField body="usi" type="string">
  Unique Superannuation Identifier (USI) for the employee's chosen super fund/product. Changing this value (like name, gender, dob, address, or taxFileNumber) re-triggers MVR verification.
</ParamField>

<ParamField body="memberNumber" type="string">
  Member number issued by the superannuation fund for this employee. This will be sent in the Superannuation clearing house member payload and used by the fund to directly match contributions to the member's account. Must be a string; cannot be blank or whitespace-only. Only alphanumeric characters, hyphens, underscores, and spaces are allowed — no other special characters. Must be unique per client - cannot match another employee's member number under the same client.
</ParamField>

<ParamField body="employmentPayrollNumber" type="string">
  Employment / payroll number used by the employer to identify this employee in payroll systems. This will be sent as the employmentPayrollNumber field to Superannuation clearing house. Must be unique per client - cannot match another employee's payroll number under the same client.
</ParamField>

<ParamField body="abn" type="string">
  Australian Business Number (ABN) for the employee (typically contractors). Stored for reference only and **not** sent to Superannuation clearing house APIs. Must be exactly 11 digits, numeric characters only, first digit cannot be zero. Can be presented with or without spaces (e.g., '34623710896' or '34 623 710 896'). Must be unique per client - cannot match another employee's ABN under the same client.
</ParamField>

### Responses

| Code | Description |
|---|---|
| `200` | Employee updated successfully |
| `400` | Bad request - Invalid employee data or duplicate email (email addresses must be unique per client) |
| `401` | Unauthorized - Invalid authentication credentials |
| `404` | Employee not found |

```java Java
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;
import java.util.Base64;

public class Example {
    public static void main(String[] args) throws Exception {
        String credentials = Base64.getEncoder()
            .encodeToString("apiUsername:apiPassword".getBytes());

        String body = String.join("\n",
            "{",
            "  \"usi\": \"BTA0287AU\",",
            "  \"memberNumber\": \"MEM1001\",",
            "  \"employmentPayrollNumber\": \"EMP-000124\"",
            "}"
        );

        HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create("https://qa-super.mygigsters.com.au/v2/employees/69536c2640b85eeded2bf2e9"))
            .header("Authorization", "Basic " + credentials)
            .header("Content-Type", "application/json")
            .method("PUT", HttpRequest.BodyPublishers.ofString(body))
            .build();

        HttpResponse<String> response = HttpClient.newHttpClient()
            .send(request, HttpResponse.BodyHandlers.ofString());

        System.out.println(response.body());
    }
}
```
