---
title: "Search Employees"
description: "Searches for employees by various attributes such as USI, email, name, member number, etc. You can search by one or multiple attributes. All provided search criteria are combined with AND logic."
api: "GET https://qa-super.mygigsters.com.au/v1/employees/search"
---

Note: At least one search parameter must be provided. If no search parameters are provided, an empty array is returned.

### Search Parameters

- **usi**: Search by Unique Superannuation Identifier (exact match)
- **email**: Search by email address (partial match, case-insensitive)
- **firstName**: Search by first name (partial match, case-insensitive)
- **lastName**: Search by last name (partial match, case-insensitive)
- **memberNumber**: Search by member number (exact match)
- **employmentPayrollNumber**: Search by employment/payroll number (exact match)

### Use Case

- Find employee by USI when you only have super fund information
- Search by name when you don't know the employee ID
- Find employee by email address
- Locate employee by payroll number
