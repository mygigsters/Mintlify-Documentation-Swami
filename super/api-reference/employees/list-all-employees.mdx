---
title: "List All Employees"
description: "Retrieves all employees associated with the authenticated client. Returns a paginated list of employee records with their static information."
api: "GET https://qa-super.mygigsters.com.au/v1/employees"
---

### Pagination

This endpoint supports pagination to efficiently retrieve large employee lists. Use the `page` and `limit` query parameters to control the results.

- **page**: Page number (default: 1)
- **limit**: Number of items per page (default: 10, maximum: 100)

### Use Case

- Display list of employees in UI with pagination
- Select employees for contribution submission
- Verify which employees are onboarded
- Efficiently browse through large employee databases

### Request Parameters

<ParamField query="page" type="integer">
  Page number for pagination (default: 1)
</ParamField>

<ParamField query="limit" type="integer">
  Number of items per page (default: 10, max: 100)
</ParamField>

### Responses

| Code | Description |
|---|---|
| `200` | List of employees retrieved successfully |
| `401` | Unauthorized - Invalid authentication credentials |

### Response fields

<ResponseField name="employees" type="array">
  List of employees. Each employee object matches the Employee response model from `GET /v1/employees/{id}` and may include optional superannuation identifiers (usi, memberNumber, employmentPayrollNumber, abn).
</ResponseField>

<ResponseField name="total" type="number">
  Total count of employees across all pages
</ResponseField>

<ResponseField name="totalPages" type="number">
  Total number of pages available
</ResponseField>

<ResponseField name="hasNext" type="boolean">
  Whether there is a next page available
</ResponseField>

<ResponseField name="hasPrevious" type="boolean">
  Whether there is a previous page available
</ResponseField>

<Accordion title="Error response fields">

<ResponseField name="success" type="boolean">

<ResponseField name="message" type="string">

<ResponseField name="errorCode" type="integer">

import java.net.http.HttpResponse;
import java.util.Base64;

public class Example {
    public static void main(String[] args) throws Exception {
        String credentials = Base64.getEncoder()
            .encodeToString("apiUsername:apiPassword".getBytes());

        HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create("https://qa-super.mygigsters.com.au/v1/employees"))
            .header("Authorization", "Basic " + credentials)
            .method("GET", HttpRequest.BodyPublishers.noBody())
            .build();

        HttpResponse<String> response = HttpClient.newHttpClient()
            .send(request, HttpResponse.BodyHandlers.ofString());

        System.out.println(response.body());
    }
}
