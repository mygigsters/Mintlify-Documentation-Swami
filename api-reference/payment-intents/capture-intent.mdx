---
title: "Capture intent"
description: "The Capture Customer Intent endpoint is used to capture an amount on customer's intent."
api: "POST /customer/capture-intent"
---

### Headers

<ParamField header="X-API-Version" type="string" default="1.2" required>
  The API version to use. Supported versions are `1.1` and `1.2`.
</ParamField>

### Headers

<ParamField header="idempotency-key" type="string" required>
  A unique UUID string used to prevent duplicate operations.
</ParamField>

### Request Body Parameters

<ParamField body="intent_id" type="string" required>
  The ID of the intent to be captured.
</ParamField>

<ParamField body="amount" type="number" required>
  The amount to be captured in decimal dollars (e.g. 28833.00 for A$28,833.00). Do not pass cents.
</ParamField>

<ParamField body="currency" type="string" required>
  The currency of the payment.
</ParamField>

### Response Body

The response for the Capture Intent request is a JSON object with the following schema:

<ResponseField name="status" type="number">
  The HTTP status code of the response envelope (e.g. `200`).
</ResponseField>

<ResponseField name="message" type="string">
  Provides information related to the intent capture process (e.g. `"Payment intent captured successfully"`).
</ResponseField>

<ResponseField name="intent_id" type="string">
  The unique identifier for the captured payment intent.
</ResponseField>

Note: To inspect the payment intent lifecycle status (e.g. `SUCCEEDED`), use the [Retrieve Intent](/api-reference/payment-intents/retrieve-intent) endpoint.

### Response Codes

| Code | Description |
|---|---|
| 200 | If the request is successful, the intent is captured and the response includes the capture details. |
| 400 | Bad Request. Missing required parameters (e.g. 'intent_id is required, amount is required') or invalid amount. |
| 401 | Unauthorized. Missing or invalid credentials. |
| 404 | Not Found. The specified intentId does not exist. |
| 409 | Conflict. The intent is in a state that cannot be captured. |
| 500 | Internal Server Error. |

```java Java
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;
import java.util.Base64;

public class Example {
    public static void main(String[] args) throws Exception {
        String credentials = Base64.getEncoder()
            .encodeToString("YOUR_UUID:YOUR_SECRET".getBytes());

        String body = String.join("\n",
            "{",
            "  \"amount\": 250,",
            "  \"currency\": \"AUD\",",
            "  \"intent_id\": \"int_hkdmzwzw6h6nmtxbe2u\"",
            "}"
        );

        HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create("https://qa-payments.mygigsters.com.au/api/v1/customer/capture-intent"))
            .header("Authorization", "Basic " + credentials)
            .header("idempotency-Key", "7b80a149-16ff-4dc8-8eb1-f1f4cfd0d578")
            .header("X-API-Version", "1.2")
            .header("Content-Type", "application/json")
            .method("POST", HttpRequest.BodyPublishers.ofString(body))
            .build();

        HttpResponse<String> response = HttpClient.newHttpClient()
            .send(request, HttpResponse.BodyHandlers.ofString());

        System.out.println(response.body());
    }
}
```
