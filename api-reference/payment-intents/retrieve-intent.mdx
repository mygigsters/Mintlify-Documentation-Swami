---
title: "Retrieve intent"
description: "The Retrieve Customer Intent endpoint is used to retrieve the intent details for a customer."
api: "GET /customer/retrieve-intent/{intent_id}"
---

### Headers

<ParamField header="X-API-Version" type="string" default="1.2" required>
  The API version to use. Supported versions are `1.1` and `1.2`.
</ParamField>

### Path Parameters

<ParamField path="intent_id" type="string" required>
  The unique identifier of the payment intent to retrieve.
</ParamField>

### Response Body

The response for the Retrieve Intent request is a JSON object with the following schema:

| Field | Type | Description |
|---|---|---|
| `status` | number | HTTP status code envelope (e.g., `200`). Note: The payment lifecycle status of the intent is located in `response.intent_status` and `data.status`. |
| `message` | string | A message describing the result of the intent retrieval. |
| `response`object | object | Summary intent details. |
| ↳`id` | string | The unique identifier of the payment intent. |
| ↳`amount` | number | The amount associated with the intent. |
| ↳`currency` | string | The currency of the intent (e.g., `AUD`). |
| ↳`refund` | number | The refunded amount, if any. |
| ↳`intent_status` | string | The status of the intent (e.g., `SUCCEEDED`, `REQUIRES_PAYMENT_METHOD`). |
| `data`object | object | Detailed payment intent object containing transaction information. |
| ↳`id` | string | The unique identifier of the payment intent. |
| ↳`request_id` | string | The unique request identifier. |
| ↳`amount` | number | The total intent amount. |
| ↳`currency` | string | The three-letter ISO currency code (e.g., `AUD`). |
| ↳`merchant_order_id` | string | Merchant order reference or booking ID. |
| ↳`descriptor` | string | Statement descriptor for the transaction. |
| ↳`status` | string | The status of the payment intent (e.g., `SUCCEEDED`). |
| ↳`captured_amount` | number | Total amount captured. |
| ↳`payment_link_id` | string | ID of the associated payment link, if applicable. |
| ↳`return_url` | string | Redirect return URL after payment completion. |
| ↳`created_at` | string | Timestamp when the intent was created. |
| ↳`updated_at` | string | Timestamp when the intent was last updated. |
| ↳`customer`object | object | Customer information associated with the intent. |
| ↳`email` | string | Customer email address. |
| ↳`name` | string | Customer name. |
| ↳`latest_payment_attempt`object | object | Details of the most recent payment attempt. |
| ↳`id` | string | Unique identifier of the payment attempt. |
| ↳`amount` | number | Amount for this payment attempt. |
| ↳`currency` | string | Currency code of the attempt. |
| ↳`status` | string | Status of the attempt (e.g., `PAID`). |
| ↳`provider_transaction_id` | string | Provider transaction identifier. |
| ↳`authorization_code` | string | Authorization approval code. |
| ↳`payment_method`object | object | Payment method details used. |
| ↳`type` | string | Payment method type (e.g., `card`). |
| ↳`card`object | object | Card details. |
| ↳`brand` | string | Card brand (e.g., `visa`, `mastercard`). |
| ↳`last4` | string | Last 4 digits of the card number. |
| ↳`expiry_month` | string | Two-digit card expiration month. |
| ↳`expiry_year` | string | Four-digit card expiration year. |
| ↳`card_type` | string | Type of card (e.g., `DEBIT`, `CREDIT`). |

### Response Codes

| Code | Description |
|---|---|
| 200 | If the request is successful, the intent details are retrieved and the response includes the complete intent information. |
| 400 | Bad Request. Invalid parameters or format. |
| 401 | Unauthorized. Missing or invalid credentials. |
| 404 | Not Found. The specified intentId does not exist. |
| 500 | Internal Server Error. |

<RequestExample>

```bash cURL
curl -X GET https://qa-payments.mygigsters.com.au/api/v1/customer/retrieve-intent/int_hkdmn5lcqh5eo1jfsg7 \
  -u "YOUR_UUID:YOUR_SECRET" \
  -H "X-API-Version: 1.2" \
  -H "Content-Type: application/json"
```

</RequestExample>
