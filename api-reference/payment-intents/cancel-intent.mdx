---
title: "Cancel intent"
description: "The Cancel Customer Intent endpoint is used to cancel a customer's intent with the provided details."
api: "POST /customer/cancel-intent"
---

### Headers

<ParamField header="X-API-Version" type="string" default="1.2" required>
  The API version to use. Supported versions are `1.1` and `1.2`.
</ParamField>

### Headers

<ParamField header="idempotency-key" type="string" required>
  A unique UUID string used to prevent duplicate operations.
</ParamField>

### Request Body Parameters

<ParamField body="intent_id" type="string" required>
  The unique identifier of the intent to be cancelled.
</ParamField>

<ParamField body="reason" type="string" required>
  The reason for cancelling the intent.
</ParamField>

### Response Body

The response for the Cancel Intent request is a JSON object with the following schema:

<ResponseField name="message" type="string">
  Provides information related to the intent cancellation process.
</ResponseField>

<ResponseField name="status" type="number">
  Indicates the status code of the intent cancellation request.
</ResponseField>

<ResponseField name="intent_id" type="string">
  The unique identifier of the cancelled intent.
</ResponseField>

### Response Codes

| Code | Description |
|---|---|
| 200 | If the request is successful, the intent is cancelled and the response includes the cancellation details and intent ID. |
| 400 | Bad Request. Invalid parameters or invalid cancellation request. |
| 401 | Unauthorized. Missing or invalid credentials. |
| 404 | Not Found. The specified intentId does not exist. |
| 409 | Conflict. The intent cannot be cancelled from its current state. |
| 500 | Internal Server Error. |

import java.net.http.HttpRequest;

public class Example {
    public static void main(String[] args) throws Exception {

            .encodeToString("YOUR_UUID:YOUR_SECRET".getBytes());

        String body = String.join("\n",

            "}"
        );

        HttpRequest request = HttpRequest.newBuilder()

            .header("Authorization", "Basic " + credentials)
            .header("idempotency-Key", "7b80a149-16ff-4dc8-8eb1-f1f4cfd0d579")
            .header("X-API-Version", "1.2")
            .header("Content-Type", "application/json")
            .method("POST", HttpRequest.BodyPublishers.ofString(body))
            .build();

        HttpResponse<String> response = HttpClient.newHttpClient()
            .send(request, HttpResponse.BodyHandlers.ofString());

        System.out.println(response.body());
    }
