---
title: "Get all invoices"
description: "This endpoint retrieves all invoices with support for search, date filters, and pagination."
api: "GET /get-all-invoices"
---

### Headers

<ParamField header="X-API-Version" type="string" default="1.2" required>
  The API version to use. Supported versions are `1.1` and `1.2`.
</ParamField>

### Query Parameters

<ParamField query="page" type="number">
  Page number for pagination (default: 1).
</ParamField>

<ParamField query="limit" type="number">
  Number of records per page (default: 10, max: 100).
</ParamField>

<ParamField query="search" type="string">
  Search keyword to filter invoices by invoice number or merchant name.
</ParamField>

<ParamField query="start_date" type="string">
  Filter invoices starting from this date (Format: YYYY-MM-DD).
</ParamField>

<ParamField query="end_date" type="string">
  Filter invoices up to this date (Format: YYYY-MM-DD).
</ParamField>

### Response Body

| Field | Type | Description |
|---|---|---|
| `status` | number | Indicates the status code of the request. |
| `current_page` | number | The current page number. |
| `total_pages` | number | The total number of pages available. |
| `total_files` | number | The total number of invoices matched. |
| `page_size` | number | The number of invoices per page. |
| `invoices`array | array | An array of invoice objects. |
| ↳`invoice_id` | string | Unique identifier of the invoice. |
| ↳`invoice_number` | string | The invoice number. |
| ↳`invoice_date` | string | Date the invoice was issued (Format: YYYY-MM-DD). |
| ↳`invoice_due_date` | string | Date by which payment is due (Format: YYYY-MM-DD). |
| ↳`invoice_amount` | number | Total amount of the invoice. |
| ↳`merchant` | string | The merchant name. |
| ↳`is_xero_synced` | boolean | Indicates if the invoice is synced with Xero. |
| ↳`payment_status` | string | Current status of the payment (e.g., `PAID`, `UNPAID`). |
| ↳`type` | string | Type of invoice (e.g. `cost_of_sales`, `sales`). |
| ↳`url` | string | URL to download/view the invoice PDF. |
| ↳`created_at` | string | Timestamp when the invoice was created. |

### Response Codes

| Code | Description |
|---|---|
| 200 | The request was successful and returns the list of invoices. |
| 400 | Bad Request. Invalid filter parameters. |
| 401 | Unauthorized. Missing or invalid credentials. |
| 500 | Internal Server Error. |

        HttpRequest request = HttpRequest.newBuilder()

            .header("X-API-Version", "1.2")
            .header("Content-Type", "application/json")
            .method("GET", HttpRequest.BodyPublishers.noBody())
            .build();

        HttpResponse<String> response = HttpClient.newHttpClient()
            .send(request, HttpResponse.BodyHandlers.ofString());

        System.out.println(response.body());
    }
}
