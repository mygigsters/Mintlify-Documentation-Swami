---
title: "Retrieve credit note"
description: "Retrieves the full details of a specific credit note including balance calculations, associated customer and invoice details, and current lifecycle status."
api: "GET /credit-notes/{id}"
---

### Headers

<ParamField header="X-API-Version" type="string" default="1.2" required>
  The API version to use. Supported versions are `1.1` and `1.2`.
</ParamField>

### Path Parameters

<ParamField path="id" type="string" required>
  The unique ID (UUID) of the credit note to retrieve.
</ParamField>

### Response Body

<ResponseField name="data.id" type="string">
  Unique identifier (UUID) of the credit note.
</ResponseField>

<ResponseField name="data.creditNoteNumber" type="string">
  Credit note code (e.g. `CN-2026-0089` or `DRAFT`).
</ResponseField>

<ResponseField name="data.status" type="string">
  Current status (`DRAFT`, `ISSUED`, `PARTIALLY_APPLIED`, `FULLY_APPLIED`, or `VOIDED`).
</ResponseField>

<ResponseField name="data.totalAmount" type="number">
  Total credit granted.
</ResponseField>

<ResponseField name="data.appliedAmount" type="number">
  Cumulative amount applied to date.
</ResponseField>

<ResponseField name="data.remainingAmount" type="number">
  Remaining credit balance available for invoice allocation.
</ResponseField>

<ResponseField name="data.invoiceId" type="string">
  Target invoice UUID.
</ResponseField>

<ResponseField name="data.customerName" type="string">
  Associated customer or client name.
</ResponseField>

### Response Codes

| Code | Description |
|---|---|
| 200 | Credit note details retrieved successfully. |
| 401 | Unauthorized. Missing or invalid credentials. |
| 404 | Not Found. Credit note not found. |
| 500 | Internal server error. |

<RequestExample>

```bash cURL
curl -X GET https://qa-payments.mygigsters.com.au/api/v1/credit-notes/1 \
  -u "YOUR_UUID:YOUR_SECRET" \
  -H "X-API-Version: 1.2" \
  -H "Content-Type: application/json"
```

</RequestExample>
