---
title: "Create draft credit note"
description: "Creates a new credit note in DRAFT state against an invoice. Drafts can be edited or deleted prior to official issuance."
api: "POST /credit-notes/draft"
---

### Headers

<ParamField header="X-API-Version" type="string" default="1.2" required>
  The API version to use. Supported versions are `1.1` and `1.2`.
</ParamField>

<ParamField header="Idempotency-Key" type="string">
  A unique key so a retried request is not processed twice.
</ParamField>

### Request Body Parameters

<ParamField body="invoice_id" type="string" required>
  The unique identifier (UUID) of the target invoice to credit.
</ParamField>

<ParamField body="amount" type="number" required>
  The total amount to credit. Must be greater than 0.
</ParamField>

<ParamField body="currency" type="string">
  Three-letter ISO currency code (e.g. `AUD`, `USD`, `EUR`). Defaults to `AUD`.
</ParamField>

<ParamField body="reason" type="string" required>
  Reason category for issuing credit (e.g. Overbilled service hours, Customer discount / Service dispute, Billing error / Price adjustment).
</ParamField>

<ParamField body="description" type="string">
  Detailed explanatory notes or accounting memo.
</ParamField>

### Response Body

<ResponseField name="status" type="number">
  HTTP status code (200 / 201).
</ResponseField>

<ResponseField name="message" type="string">
  Confirmation message describing the operation result.
</ResponseField>

<ResponseField name="data.id" type="string">
  Unique identifier of the created credit note draft.
</ResponseField>

<ResponseField name="data.creditNoteNumber" type="string">
  Set to `DRAFT` until the credit note is officially issued.
</ResponseField>

<ResponseField name="data.status" type="string">
  Current lifecycle state, initially `DRAFT`.
</ResponseField>

<ResponseField name="data.totalAmount" type="number">
  The total credit amount for this credit note.
</ResponseField>

<ResponseField name="data.remainingAmount" type="number">
  Unallocated credit balance remaining.
</ResponseField>

### Response Codes

| Code | Description |
|---|---|
| 200 | Draft credit note created successfully. |
| 400 | Bad Request. Missing required fields or invalid credit amount. |
| 401 | Unauthorized. Missing or invalid credentials. |
| 404 | Not Found. Target invoice not found. |
| 500 | Internal server error. |
