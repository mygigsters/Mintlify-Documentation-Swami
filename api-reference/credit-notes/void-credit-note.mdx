---
title: "Void credit note"
description: "Permanently revokes an issued credit note with a required audit reason. Status transitions to VOIDED and any unallocated balance is removed."
api: "POST /credit-notes/{id}/void"
---

### Headers

<ParamField header="X-API-Version" type="string" default="1.2" required>
  The API version to use. Supported versions are `1.1` and `1.2`.
</ParamField>

<ParamField header="Idempotency-Key" type="string">
  A unique key so a retried request is not processed twice.
</ParamField>

### Path Parameters

<ParamField path="id" type="string" required>
  The unique ID (UUID) of the credit note to void.
</ParamField>

### Request Body Parameters

<ParamField body="reason" type="string" required>
  Mandatory justification explaining why the credit note is being cancelled.
</ParamField>

### Response Body

<ResponseField name="status" type="number">
  HTTP status code (200).
</ResponseField>

<ResponseField name="message" type="string">
  Confirmation message (e.g. `Credit note voided successfully`).
</ResponseField>

<ResponseField name="data.status" type="string">
  Updated state: `VOIDED`.
</ResponseField>

<ResponseField name="data.voidReason" type="string">
  The audit reason recorded for voiding.
</ResponseField>

<ResponseField name="data.voidedAt" type="string">
  ISO 8601 timestamp of cancellation.
</ResponseField>

### Response Codes

| Code | Description |
|---|---|
| 200 | Credit note voided successfully. |
| 400 | Bad Request. Missing void reason or credit note is already VOIDED. |
| 401 | Unauthorized. Missing or invalid credentials. |
| 404 | Not Found. Credit note ID not found. |
| 500 | Internal server error. |

<RequestExample>

```bash cURL
curl -X POST https://qa-payments.mygigsters.com.au/api/v1/credit-notes/1/void \
  -u "YOUR_UUID:YOUR_SECRET" \
  -H "idempotency-Key: cn-req-void-005" \
  -H "X-API-Version: 1.2" \
  -H "Content-Type: application/json" \
  -d '{
  "reason": "Credit note issued by mistake"
}'
```

</RequestExample>
