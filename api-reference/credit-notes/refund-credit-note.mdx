---
title: "Refund credit note"
description: "Processes a payment gateway refund against the credit note balance. The refund is disbursed directly back to the customer's original payment method, remaining balance is deducted, and a refund allocation is created for auditing."
api: "POST /credit-notes/{id}/refund"
---

### Headers

<ParamField header="X-API-Version" type="string" default="1.2" required>
  The API version to use. Supported versions are `1.1` and `1.2`.
</ParamField>

<ParamField header="Idempotency-Key" type="string">
  A unique key so a retried request is not processed twice.
</ParamField>

### Path Parameters

<ParamField path="id" type="string" required>
  Credit note number (e.g. `CN-8466`) or unique ID from which balance is refunded.
</ParamField>

### Request Body Parameters

<ParamField body="amount" type="number" required>
  The amount to refund to customer. Cannot exceed `remainingAmount`.
</ParamField>

<ParamField body="reason" type="string" required>
  Audit reason for issuing the refund (e.g. `Customer requested refund for unused service`).
</ParamField>

### Response Body

<ResponseField name="success" type="boolean">
  Status flag (`true` on success).
</ResponseField>

<ResponseField name="message" type="string">
  Confirmation message (`Credit note refund processed successfully`).
</ResponseField>

<ResponseField name="data.creditNote.status" type="string">
  Updated state: `PARTIALLY_REFUNDED` or `REFUNDED`.
</ResponseField>

<ResponseField name="data.creditNote.refundedAmount" type="string">
  Total cumulative amount refunded to customer.
</ResponseField>

<ResponseField name="data.creditNote.remainingAmount" type="string">
  Remaining credit balance available.
</ResponseField>

<ResponseField name="data.creditNote.allocations" type="array">
  List of allocations including the newly recorded Airwallex refund allocation entry.
</ResponseField>

<ResponseField name="data.refund.refundId" type="string">
  Payment gateway refund reference ID (e.g. `rfd_sgpvwpnw7hmk2c9sx5s_pihj7h`).
</ResponseField>

<ResponseField name="data.refund.status" type="string">
  Gateway status (e.g. `RECEIVED`).
</ResponseField>

### Response Codes

| Code | Description |
|---|---|
| 200 | Credit note refund processed successfully. |
| 400 | Bad Request. Amount exceeds remaining credit balance or reason is missing. |
| 401 | Unauthorized. Missing or invalid credentials. |
| 404 | Not Found. Credit note not found. |
| 500 | Internal server error. |
