The MyGigsters Payments API is a REST API. It accepts and returns JSON, and uses standard HTTP status codes.

## Base URLs

| Environment | Base URL |
|---|---|
| Demo (QA) | `https://qa-payments.mygigsters.com.au/api/v1` |
| Production | `https://prod-payments.mygigsters.com.au/api/v1` |

The examples and the interactive playground in this reference use the demo environment. See [Environments](/get-started/environments).

## Authentication

Send your API key pair with HTTP Basic authentication, and include the version header on every request.

```bash
curl https://qa-payments.mygigsters.com.au/api/v1/customer/{customer_id} \
  -u "YOUR_UUID:YOUR_SECRET" \
  -H "X-API-Version: 1.2"
```

Partner endpoints use a Bearer token instead. Get one from [Authenticate partner](/api-reference/partner-account/partner-authenticate).

See [Authentication](/get-started/authentication) for details.

## Conventions

- **Versioning:** send `X-API-Version: 1.2`. See [API versioning](/security/versioning).
- **Field names:** version 1.2 uses snake_case for request and response fields.
- **Idempotency:** send an `idempotency-Key` header on `POST` and `PUT` requests. See [Idempotency](/security/idempotency).
- **Errors:** every error returns the same JSON format. See [Errors and conventions](/api-reference/errors-and-conventions).
