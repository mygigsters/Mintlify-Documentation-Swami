---
title: "Get connected account transactions"
description: "Retrieves a paginated ledger of financial transactions (both debits and credits) for a specific connected account within a given date range. Each transaction record includes amount, currency, counterparty merchant, settlement status,..."
api: "GET /connected-account/{account_id}/transactions"
authMethod: "bearer"
---

### Headers

<ParamField header="x-api-version" type="string" required>
  Target API version (e.g. `1.2`).
</ParamField>

### Path Parameters

<ParamField path="account_id" type="string" required>
  The unique client UUID of the connected account (e.g. `4407c3ba-10c9-4822-9f51-c2c96692f8d7`).
</ParamField>

### Query Parameters

<ParamField query="from_post_at" type="string">
  ISO 8601 UTC timestamp to retrieve transactions posted on or after this date (e.g. `2026-10-02T00:00:00Z`).
</ParamField>

<ParamField query="to_post_at" type="string">
  ISO 8601 UTC timestamp to retrieve transactions posted on or before this date (e.g. `2026-10-08T00:00:00Z`).
</ParamField>

<ParamField query="page_size" type="number">
  Number of transaction records to return per page (default is `10`).
</ParamField>

<ParamField query="page" type="number">
  Page number to retrieve for pagination (default is `1`).
</ParamField>

### Response Body

<ResponseField name="success" type="boolean">
  Indicates whether the transaction query succeeded (`true`).
</ResponseField>

<ResponseField name="message" type="string">
  Descriptive message of the query outcome.
</ResponseField>

<ResponseField name="data" type="object">
  Wrapper object containing the array of transaction records.
</ResponseField>

<ResponseField name="data.transactions" type="array of objects">
  Chronological list of financial transactions executed on the connected account.
</ResponseField>

<ResponseField name="data.transactions[].id" type="number">
  Unique internal ID of the transaction record.
</ResponseField>

<ResponseField name="data.transactions[].direction" type="string">
  Flow of funds: `credit` (incoming) or `debit` (outgoing).
</ResponseField>

<ResponseField name="data.transactions[].amount" type="string">
  Formatted monetary amount of the transaction (e.g. `"-440.00"`, `"500000.00"`).
</ResponseField>

<ResponseField name="data.transactions[].type" type="string">
  Transaction rail type: `TRANSFER`, `LOCAL`, `CARD_PAYMENT`, etc.
</ResponseField>

<ResponseField name="data.transactions[].currency" type="string">
  Three-letter ISO currency code (e.g. `AUD`).
</ResponseField>

<ResponseField name="data.transactions[].merchant" type="string">
  Name of the merchant, beneficiary, or counterparty entity.
</ResponseField>

<ResponseField name="data.transactions[].status" type="string">
  Settlement status: `SETTLED`, `PROCESSING`, `REQUIRES_PAYMENT_METHOD`, etc.
</ResponseField>

<ResponseField name="data.transactions[].occurredAt" type="string">
  ISO 8601 UTC timestamp when the transaction was initiated or processed.
</ResponseField>

<ResponseField name="data.transactions[].reference" type="string">
  Reference note or remittance information attached to the transfer.
</ResponseField>

<ResponseField name="data.transactions[].raw" type="object">
  Complete raw settlement payload including balance snapshots, fees, and provider routing details.
</ResponseField>

<ResponseField name="summary" type="object">
  Aggregate transaction statistics across the entire filtered period.
</ResponseField>

<ResponseField name="summary.all" type="number">
  Total number of transactions matching the date range.
</ResponseField>

<ResponseField name="summary.credit" type="number">
  Total number of incoming credit transactions.
</ResponseField>

<ResponseField name="summary.debit" type="number">
  Total number of outgoing debit transactions.
</ResponseField>

<ResponseField name="pagination" type="object">
  Pagination metadata including `currentPage`, `pageSize`, `totalCount`, and `totalPages`.
</ResponseField>

### Response Codes

| Code | Description |
|---|---|
| 200 | Transactions retrieved successfully. |
| 401 | Unauthorized. Missing, expired, or invalid partner Bearer token. |
| 404 | Not Found. Connected account with the provided myGigsterId does not exist. |
| 500 | Internal Server Error. |
