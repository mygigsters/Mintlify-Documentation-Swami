---
title: "Create connected account"
description: "Onboards and registers a connected client account under the authenticated partner. Automatically generates a unique client UUID (account_id) and a secure, time-sensitive KYC magic link (kyc_magic_link) for direct customer verification."
api: "POST /connected-account"
authMethod: "bearer"
---

### Headers

<ParamField header="x-api-version" type="string" required>
  Target API version (e.g. `1.2`).
</ParamField>

### Request Body Parameters

<ParamField body="legal_entity_type" type="string" required>
  Legal entity type of the client. Allowed values: `BUSINESS`, `INDIVIDUAL`.
</ParamField>

<ParamField body="business_name" type="string">
  Registered trade name or company name. Required if `legalEntityType` is `BUSINESS`.
</ParamField>

<ParamField body="full_name" type="string" required>
  Full legal name of the primary contact person or authorized representative.
</ParamField>

<ParamField body="email" type="string" required>
  Primary contact and administrative email for the client connected account.
</ParamField>

<ParamField body="phone" type="string" required>
  Primary contact phone number (e.g. `+61412340918`).
</ParamField>

<ParamField body="abn" type="string">
  11-digit Australian Business Number (e.g. `99 687 807 763`). Required if entity is a registered Australian business.
</ParamField>

<ParamField body="addrline1" type="string" required>
  Street address line 1 (e.g. `123 Collins St`).
</ParamField>

<ParamField body="suburb" type="string" required>
  Suburb, locality, or town (e.g. `Melbourne`).
</ParamField>

<ParamField body="state" type="string" required>
  State or territory code (e.g. `VIC`, `NSW`, `QLD`).
</ParamField>

<ParamField body="postcode" type="string" required>
  Postal code (e.g. `3000`).
</ParamField>

<ParamField body="country_code" type="string" required>
  Two-letter ISO 3166-1 alpha-2 country code (e.g. `AU`).
</ParamField>

### Response Body

<ResponseField name="message" type="string">
  Status message (e.g. `Signup successful`).
</ResponseField>

<ResponseField name="account_id" type="string">
  The unique UUID identifier assigned to the connected account in MyGigsters.
</ResponseField>

<ResponseField name="kyc_magic_link" type="string">
  Secure, pre-authenticated onboarding URL. Send or redirect your client to this magic link so they can complete identity verification and KYC checks.
</ResponseField>

### Response Codes

| Code | Description |
|---|---|
| 200 / 201 | Signup successful. Client created and KYC link generated. |
| 400 | Bad Request. Missing required registration fields or invalid format. |
| 401 | Unauthorized. Missing, expired, or invalid partner Bearer token. |
| 409 | Conflict. An account with this email or ABN already exists. |
| 500 | Internal Server Error. An unexpected error occurred on the server. |
