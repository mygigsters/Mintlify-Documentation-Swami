---
title: "Add bank details"
description: "This endpoint allows you to add bank details for a worker."
api: "POST /worker-bank-details"
---

### Headers

<ParamField header="X-API-Version" type="string" default="1.2" required>
  The API version to use. Supported versions are `1.1` and `1.2`.
</ParamField>

### Headers

<ParamField header="idempotency-key" type="string" required>
  A unique UUID string used to prevent duplicate operations.
</ParamField>

### Request Body Parameters

<ParamField body="bsb" type="string">
  065163 for Sandbox Environment.
</ParamField>

<ParamField body="ifsc_code" type="string">
  Applicable for Indian bank accounts.
</ParamField>

<ParamField body="upi_id" type="string">
  Applicable for Indian bank accounts.
</ParamField>

<ParamField body="account_number" type="string" required>
  12345678 for Sandbox Environment.
</ParamField>

<ParamField body="account_name" type="string" required>
  The name associated with the bank account.
</ParamField>

<ParamField body="worker_id" type="string" required>
  The unique ID of the worker.
</ParamField>

### Response Body

<ResponseField name="status" type="number">
  Indicates the status of the request. A value of 200 indicates success.
</ResponseField>

<ResponseField name="message" type="string">
  A message related to the status of the request.
</ResponseField>

### Response Codes

| Code | Description |
|---|---|
| 200 | If the request is successful, the bank details are added/updated and the response includes the status message. |
| 400 | Bad Request. Invalid or missing parameters. |
| 401 | Unauthorized. Missing or invalid credentials. |
| 404 | Not Found. The specified workerId does not exist. |
| 409 | Conflict. Duplicate idempotency key with mismatching parameters. |
| 500 | Internal Server Error. |
