---
title: "Get subscribed webhooks"
description: "Retrieves a paginated list of all active webhook subscriptions configured for the authenticated partner account."
api: "GET /partner/webhooks"
authMethod: "bearer"
---

### Headers

<ParamField header="x-api-version" type="string" required>
  Target API version (e.g. `1.2`).
</ParamField>

### Query Parameters

<ParamField query="page" type="number">
  Page number to retrieve for pagination (defaults to `1`).
</ParamField>

<ParamField query="limit" type="number">
  Number of webhook records per page (defaults to `10`).
</ParamField>

### Response Body

<ResponseField name="pagination" type="object">
  Pagination information including `currentPage`, `pageSize`, `totalCount`, and `totalPages`.
</ResponseField>

<ResponseField name="webhooks" type="array of objects">
  List of active webhook subscriptions configured for this partner.
</ResponseField>

<ResponseField name="webhooks[].id" type="number">
  Unique identifier of the webhook subscription.
</ResponseField>

<ResponseField name="webhooks[].url" type="string">
  Registered destination HTTPS endpoint URL.
</ResponseField>

<ResponseField name="webhooks[].secretKey" type="string">
  Secret key used to verify HMAC signatures of delivered payloads.
</ResponseField>

<ResponseField name="webhooks[].eventIds" type="array of numbers">
  Array of event IDs subscribed to this endpoint.
</ResponseField>

<ResponseField name="webhooks[].events" type="object">
  Full metadata for all subscribed event definitions grouped by domain category (e.g. `payout`).
</ResponseField>

<ResponseField name="webhooks[].createdAt" type="string">
  ISO 8601 timestamp when the webhook was registered.
</ResponseField>

<ResponseField name="webhooks[].updatedAt" type="string">
  ISO 8601 timestamp of last modification.
</ResponseField>

### Response Codes

| Code | Description |
|---|---|
| 200 | Subscribed webhooks retrieved successfully. |
| 401 | Unauthorized. Missing, expired, or invalid partner Bearer token. |
| 500 | Internal Server Error. |
