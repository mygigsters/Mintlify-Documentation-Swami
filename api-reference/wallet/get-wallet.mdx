---
title: "Get wallet balances"
description: "Returns the real-time multi-currency wallet balances (including available, pending, and reserved funds across AUD, SGD, USD, etc.) along with the associated settlement banking and clearing details."
api: "GET /wallet"
---

### Headers

<ParamField header="x-api-version" type="string" required>
  Target API version header (e.g. `1.2`).
</ParamField>

### Response Body

The response for the Get Wallet Balances request is a JSON object with the following schema:

| Field | Type | Description |
|---|---|---|
| `success` | boolean | Indicates whether the request was successful (e.g. `true`). |
| `balances`array | array of objects | List of multi-currency wallet balance figures. |
| ↳`available_amount` | number | Cleared funds available for immediate payout or transfer. |
| ↳`currency` | string | Three-letter ISO currency code (e.g. `AUD`, `SGD`, `USD`). |
| ↳`pending_amount` | number | Incoming funds currently awaiting settlement. |
| ↳`reserved_amount` | number | Funds temporarily held or reserved for pending transactions / collateral. |
| ↳`total_amount` | number | Total aggregate account balance (`available_amount + pending_amount + reserved_amount`). |
| ↳`prepayment_amount` | number | Prepayment credit balance, if any. |
| ↳`account_type` | string | Wallet classification type (e.g. `cash`). |
| `account_object`object | object | Depository and settlement banking details associated with the primary account. |
| ↳`account_name` | string | Registered bank account holder name. |
| ↳`account_number` | string | Settlement bank account number. |
| ↳`account_type` | string | Bank account classification (e.g. `Checking`, `Current`, `Cash`). |
| ↳`account_provider` | string | Banking infrastructure provider (e.g. `AIRWALLEX`). |
| ↳`bank_name` | string | Name of the depository institution (e.g. `Australia and New Zealand Banking Group Limited`). |
| ↳`bank_address` | string | Depository institution physical branch address. |
| ↳`bank_code` | string | SWIFT/BIC or bank identifier code (e.g. `CMFGUS33`). |
| ↳`bsb` | string | Routing number or Australian BSB code (e.g. `013943`). |

### Response Codes

| Code | Description |
|---|---|
| 200 | Wallet balances and account details retrieved successfully. |
| 401 | Unauthorized. Missing or invalid API key credentials. |
| 500 | Internal Server Error. |

<RequestExample>

```bash cURL

  -u "YOUR_UUID:YOUR_SECRET" \
  -H "X-API-Version: 1.2" \
  -H "Content-Type: application/json"
```
