---
title: "Get payment link status"
description: "This endpoint allows you to retrieve the status of a payment link using its unique identifier."
api: "POST /get/payment-link-status"
---

### Headers

<ParamField header="X-API-Version" type="string" default="1.2" required>
  The API version to use. Supported versions are `1.1` and `1.2`.
</ParamField>

### Request Body Parameters

<ParamField body="link_id" type="string" required>
  The unique identifier for the payment link whose status is being queried.
</ParamField>

### Response Body

The response for the Get Payment Link Status request is a JSON object with the following schema:

| Field | Type | Description |
|---|---|---|
| `status` | number | Indicates the HTTP status of the response (e.g., 200). |
| `message` | string | A message providing additional information about the request status. |
| `payment_status` | string | The current status of the payment associated with the link (e.g., `PAID`, `UNPAID`). |
| `intent_id` | string | The unique identifier for the payment intent. |
| `data`object | object | Details of the payment link. |
| ↳`id` | string | The unique identifier of the payment link. |
| ↳`url` | string | The hosted payment link URL. |
| ↳`title` | string | Title or display name of the payment link. |
| ↳`description` | string | Description of the payment link. |
| ↳`amount` | number | Total amount requested. |
| ↳`currency` | string | Currency code (e.g., `AUD`). |
| ↳`status` | string | Status of the payment link (e.g., `PAID`, `ACTIVE`). |
| ↳`active` | boolean | Whether the payment link is currently active. |
| ↳`expires_at` | string | Expiration timestamp of the payment link. |
| ↳`reference` | string | Custom reference string. |
| ↳`reusable` | boolean | Whether the link can accept multiple payments. |
| ↳`successful_payment_intent_count` | number | Number of successful payments made via this link. |
| ↳`latest_successful_payment_intent_id` | string | ID of the most recent successful payment intent. |
| ↳`created_at` | string | Creation timestamp of the payment link. |
| ↳`updated_at` | string | Timestamp of the last update. |
| `intent_data`object | object | Full payment intent details associated with the payment link. |
| ↳`id` | string | The unique identifier of the payment intent. |
| ↳`request_id` | string | The unique request identifier. |
| ↳`amount` | number | Payment amount. |
| ↳`currency` | string | Currency code (e.g., `AUD`). |
| ↳`status` | string | Intent status (e.g., `SUCCEEDED`). |
| ↳`captured_amount` | number | Captured payment amount. |
| ↳`merchant_order_id` | string | Merchant reference or order ID. |
| ↳`descriptor` | string | Statement descriptor for the transaction. |
| ↳`payment_link_id` | string | ID of the associated payment link. |
| ↳`return_url` | string | Success redirect URL. |
| ↳`created_at` | string | Timestamp when the intent was created. |
| ↳`updated_at` | string | Last updated timestamp. |
| ↳`customer`object | object | Customer details. |
| ↳`email` | string | Customer email address. |
| ↳`name` | string | Customer name. |
| ↳`latest_payment_attempt`object | object | Details of the most recent payment attempt. |
| ↳`id` | string | Unique identifier of the payment attempt. |
| ↳`amount` | number | Amount for this payment attempt. |
| ↳`currency` | string | Currency of the attempt. |
| ↳`status` | string | Status of the attempt (e.g., `PAID`). |
| ↳`provider_transaction_id` | string | Provider transaction ID. |
| ↳`authorization_code` | string | Authorization approval code. |
| ↳`payment_method`object | object | Payment method details. |
| ↳`type` | string | Payment method type (e.g., `card`). |
| ↳`card`object | object | Card details. |
| ↳`brand` | string | Card brand (e.g., `visa`). |
| ↳`last4` | string | Last 4 digits of the card number. |
| ↳`expiry_month` | string | Card expiration month. |
| ↳`expiry_year` | string | Card expiration year. |
| ↳`card_type` | string | Type of card (e.g., `DEBIT`). |

### Response Codes

| Code | Description |
|---|---|
| 200 | If the request is successful, the payment link status is retrieved and the response includes the payment status and intent ID. |
| 400 | Bad Request. Invalid or missing parameters. |
| 401 | Unauthorized. Missing or invalid credentials. |
| 404 | Not Found. The specified payment linkId was not found. |
| 500 | Internal Server Error. |

            .build();

            .send(request, HttpResponse.BodyHandlers.ofString());
