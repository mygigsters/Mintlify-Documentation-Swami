---
title: "Generate payment link"
description: "This endpoint allows you to create a payment link. (currently only supports AUD currency)."
api: "POST /create/payment-link"
---

### Headers

<ParamField header="X-API-Version" type="string" default="1.2" required>
  The API version to use. Supported versions are `1.1` and `1.2`.
</ParamField>

### Headers

<ParamField header="idempotency-key" type="string" required>
  A unique UUID string used to prevent duplicate operations.
</ParamField>

### Request Body Parameters

<ParamField body="amount" type="number" required>
  The amount for the payment link in decimal dollars (e.g. to charge $250.00 AUD, pass 250.00). Do not pass cents.
</ParamField>

<ParamField body="currency" type="string" required>
  The currency of the payment.
</ParamField>

<ParamField body="description" type="string" required>
  Description of the payment link.
</ParamField>

<ParamField body="expires_at" type="string" required>
  Expiry date and time for the payment link, must be in future.
</ParamField>

<ParamField body="reference" type="string" required>
  Reference for the payment link.
</ParamField>

<ParamField body="title" type="string" required>
  Title of the payment link.
</ParamField>

<ParamField body="reusable" type="boolean">
  If true, the payment link can be reused for multiple payments. Defaults to false.
</ParamField>

### Response Body

The response for the Generate Payment Link request is a JSON object with the following schema:

<ResponseField name="message" type="string">
  Provides information about the payment link generation process.
</ResponseField>

<ResponseField name="id" type="string">
  The unique identifier for the generated payment link.
</ResponseField>

<ResponseField name="url" type="string">
  The URL of the generated payment link.
</ResponseField>

### Response Codes

| Code | Description |
|---|---|
| 200 | If the request is successful, the payment link is generated and the response includes the link details and URL. |
| 400 | Bad Request. Invalid parameters or invalid amount format. |
| 401 | Unauthorized. Missing or invalid credentials. |
| 409 | Conflict. Duplicate idempotency key with mismatching parameters. |
| 500 | Internal Server Error. |
