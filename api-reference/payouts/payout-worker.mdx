---
title: "Payout worker"
description: "This endpoint allows the user to initiate a bank payout for a worker."
api: "POST /worker-bank-payout"
---

### Headers

<ParamField header="X-API-Version" type="string" default="1.2" required>
  The API version to use. Supported versions are `1.1` and `1.2`.
</ParamField>

### Headers

<ParamField header="idempotency-key" type="string" required>
  A unique UUID string used to prevent duplicate operations.
</ParamField>

### Request Body Parameters

<ParamField body="worker_id" type="string" required>
  The unique ID of the worker initiating the payout.
</ParamField>

<ParamField body="job_id" type="string">
  The ID of the job for which the payout is being initiated. Either job ID or reference is required.
</ParamField>

<ParamField body="reference" type="string">
  The reference for the payout request. Either job ID or reference is required.
</ParamField>

<ParamField body="amount" type="number" required>
  The amount to be transferred in decimal dollars (e.g. 500.00). Do not pass cents.
</ParamField>

<ParamField body="currency" type="string" required>
  The currency of the payout (e.g. AUD).
</ParamField>

<ParamField body="against_invoice" type="boolean">
  Indicates whether the payout should be processed against an invoice.
</ParamField>

<ParamField body="invoice_id" type="string">
  The ID of the invoice against which the payout should be processed. Required when against_invoice is true.
</ParamField>

<ParamField body="mode" type="string">
  The payout mode defaults to `BANK_TRANSFER` for Australia and `IMPS` for India. Australia supports `NPP` and `BANK_TRANSFER`. India supports `IMPS`, `NEFT`, `RTGS`, and `UPI`. Make sure the mode you choose is supported in the recipient's country.
</ParamField>

### Response Body

| Field | Type | Description |
|---|---|---|
| `status` | number | Indicates the status of the payout request. |
| `message` | string | Provides information about the payout process result. |
| `payout_result`object | object | Contains payout processing result details. |
| ↳`message` | string | Message about the payout process completion. |
| ↳`transfer_results`array | array | Array containing transfer result details. |
| ↳`amount` | number | The amount transferred. |
| ↳`transfer_id` | string | Unique ID for the processed transfer. |
| ↳`message` | string | Indicates if the payout was successful. |

### Response Codes

| Code | Description |
|---|---|
| 200 | If the request is successful, the payout is processed and the response includes the transfer details and results. |
| 400 | Bad Request. Invalid parameters or invalid amount format. |
| 401 | Unauthorized. Missing or invalid credentials. |
| 404 | Not Found. The specified workerId, jobId or invoiceId does not exist. |
| 409 | Conflict. Duplicate idempotency key with mismatching parameters. |
| 500 | Internal Server Error. |

### Examples

| Mode | Description |
|---|---|
| IMPS | IMPS transfers support amounts from ₹1 to ₹5,00,000 per transaction. |
| NEFT | NEFT transfers support amounts starting from ₹1 with no upper transaction limit. |
| RTGS | RTGS transfers require a minimum amount of ₹2,00,000 and have no upper transaction limit. |
| UPI | UPI transfers support amounts from ₹1 to ₹1,00,000 per transaction. |
