---
title: "Talent payouts"
description: "This endpoint processes a payout to a talent (worker) using their bank details."
api: "POST /payout-talent"
---

### Headers

<ParamField header="X-API-Version" type="string" default="1.2" required>
  The API version to use. Supported versions are `1.1` and `1.2`.
</ParamField>

### Headers

<ParamField header="idempotency-key" type="string" required>
  A unique UUID string used to prevent duplicate operations.
</ParamField>

### Request Body Parameters

<ParamField body="full_name" type="string" required>
  Full name of the worker (beneficiary).
</ParamField>

<ParamField body="email" type="string" required>
  Email address of the worker (beneficiary).
</ParamField>

<ParamField body="phone" type="string" required>
  Phone number of the worker (beneficiary).
</ParamField>

<ParamField body="reference" type="string" required>
  Unique reference for the payout (example: job reference).
</ParamField>

<ParamField body="amount" type="number" required>
  Amount to be paid to the worker in decimal dollars (e.g. 109.00). Do not pass cents.
</ParamField>

<ParamField body="currency" type="string" required>
  Currency of the amount to be paid to the worker.
</ParamField>

<ParamField body="bsb_number" type="string" required>
  The BSB number of the worker's bank.
</ParamField>

<ParamField body="account_number" type="string" required>
  The bank account number of the worker.
</ParamField>

<ParamField body="account_name" type="string" required>
  The name associated with the bank account.
</ParamField>

<ParamField body="mode" type="string">
  The payout mode. Defaults to `BANK_TRANSFER`. `NPP` is also supported. Make sure the mode you choose is supported in the recipient's country.
</ParamField>

### Response Body

| Field | Type | Description |
|---|---|---|
| `status` | number | Status code of the request. 200 indicates success. |
| `message` | string | Summary message of the payout status. |
| `payout_result`object | object | Contains payout processing result. |
| ↳`message` | string | Summary message of the payout process. |
| ↳`transfer_results`array | array | List of transfer results for payouts. |
| ↳`amount` | number | Amount transferred in each payout transaction. |
| ↳`currency` | string | Currency of the amount transferred in each payout transaction. |
| ↳`transfer_id` | string | Unique ID for the processed payout transfer. |
| ↳`message` | string | Indicates if the payout was successful. |

### Response Codes

| Code | Description |
|---|---|
| 200 | Payout processed successfully. |
| 400 | Bad Request. Invalid parameters or invalid amount format. |
| 401 | Unauthorized. Missing or invalid credentials. |
| 409 | Conflict. Duplicate idempotency key with mismatching parameters. |
| 500 | Internal Server Error. |
