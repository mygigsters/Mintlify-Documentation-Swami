---
title: "Verify ABN"
description: "This endpoint verifies an Australian Business Number (ABN) and returns detailed business registration information including entity name, status, address, and GST registration details."
api: "POST /verify/abn"
---

### Headers

<ParamField header="X-API-Version" type="string" default="1.2" required>
  The API version to use. Supported versions are `1.1` and `1.2`.
</ParamField>

### Request Body Parameters

<ParamField body="abn" type="string" required>
  The Australian Business Number to verify. Can include spaces (e.g. "34 623 710 896").
</ParamField>

### Response Body

| Field | Type | Description |
|---|---|---|
| `message` | string | A message describing the response status (e.g. "Verification Result"). |
| `data`object | object | The ABN verification result data. |
| ↳`Abn` | string | The ABN that was verified. |
| ↳`AbnStatus` | string | The current status of the ABN (e.g. "Active", "Cancelled"). |
| ↳`AbnStatusEffectiveFrom` | string | The date from which the ABN status is effective (YYYY-MM-DD). |
| ↳`Acn` | string | The Australian Company Number associated with the ABN. |
| ↳`AddressDate` | string | The date when the address was last updated (YYYY-MM-DD). |
| ↳`AddressPostcode` | string | The postcode of the registered business address. |
| ↳`AddressState` | string | The state of the registered business address (e.g. "VIC", "NSW"). |
| ↳`BusinessName` | array | A list of business names registered under this ABN. |
| ↳`EntityName` | string | The legal entity name associated with the ABN. |
| ↳`EntityTypeCode` | string | The entity type code (e.g. "PRV" for private company). |
| ↳`EntityTypeName` | string | The full entity type name (e.g. "Australian Private Company"). |
| ↳`Gst` | string | The date from which the entity is registered for GST (YYYY-MM-DD). |
| ↳`Message` | string | Additional message from the verification service (empty if no issues). |

### Response Codes

| Code | Description |
|---|---|
| 200 | The ABN was successfully verified and the business details are returned. |
| 400 | Bad Request. The ABN format is invalid or missing. |
| 401 | Unauthorized. Missing or invalid credentials. |
| 500 | Internal Server Error. |

```java Java
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;
import java.util.Base64;

public class Example {
    public static void main(String[] args) throws Exception {
        String credentials = Base64.getEncoder()
            .encodeToString("YOUR_UUID:YOUR_SECRET".getBytes());

        String body = String.join("\n",
            "{",
            "  \"abn\": \"34 623 710 896\"",
            "}"
        );

        HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create("https://qa-payments.mygigsters.com.au/api/v1/verify/abn"))
            .header("Authorization", "Basic " + credentials)
            .header("X-API-Version", "1.2")
            .header("Content-Type", "application/json")
            .method("POST", HttpRequest.BodyPublishers.ofString(body))
            .build();

        HttpResponse<String> response = HttpClient.newHttpClient()
            .send(request, HttpResponse.BodyHandlers.ofString());

        System.out.println(response.body());
    }
}
```
