---
title: "Verify passport"
description: "This endpoint verifies an Australian passport against official government records. It performs a field-by-field comparison and returns match results for each submitted detail including name, birth date, travel document number, gender,..."
api: "POST /verify/passport"
---

### Headers

<ParamField header="X-API-Version" type="string" default="1.2" required>
  The API version to use. Supported versions are `1.1` and `1.2`.
</ParamField>

### Request Body Parameters

<ParamField body="birth_date" type="string" required>
  Date of birth of the passport holder. Format: YYYY-MM-DD.
</ParamField>

<ParamField body="given_name" type="string" required>
  The first name of the passport holder.
</ParamField>

<ParamField body="family_name" type="string" required>
  The last name of the passport holder.
</ParamField>

<ParamField body="travel_document_number" type="string" required>
  The passport/travel document number. One or two alpha characters followed by seven numeric characters, no spaces.
</ParamField>

<ParamField body="gender" type="string" required>
  Gender of the passport holder. Accepted values: M, F, X.
</ParamField>

### Response Body

| Field | Type | Description |
|---|---|---|
| `message` | string | A message describing the response status (e.g. "Verification Result"). |
| `data`object | object | The passport verification result data. |
| ↳`documentResult` | object | Contains the overall verification result including ActivityId, OriginatingAgencyCode, VerificationRequestNumber, and VerificationResultCode ("Y" for verified, "N" for not verified). |
| ↳`documentDetails` | object | Field-by-field match results. Each field (GivenName, FamilyName, BirthDate, TravelDocumentNumber, Gender, ExpiryDate, etc.) will have a value of "Full Match", "Partial Match", or "No Match". |
| ↳`status` | string | Overall verification status. "Y" indicates the passport is verified, "N" indicates it is not verified. |

### Response Codes

| Code | Description |
|---|---|
| 200 | The passport was successfully verified and the match results are returned. |
| 400 | Bad Request. Missing or invalid parameters. |
| 401 | Unauthorized. Missing or invalid credentials. |
| 500 | Internal Server Error. |

<RequestExample>

```bash cURL
curl -X POST https://qa-payments.mygigsters.com.au/api/v1/verify/passport \
  -u "YOUR_UUID:YOUR_SECRET" \
  -H "X-API-Version: 1.2" \
  -H "Content-Type: application/json" \
  -d '{
  "birth_date": "1972-09-02",
  "given_name": "John",
  "family_name": "Smith",
  "travel_document_number": "C5100511",
  "gender": "M"
}'
```

</RequestExample>
