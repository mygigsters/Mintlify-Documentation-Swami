---
title: "Verify driving licence"
description: "This endpoint verifies an Australian driving licence against official government records. It performs a field-by-field comparison and returns match results for each submitted detail."
api: "POST /verify/driving-license"
---

### Headers

<ParamField header="X-API-Version" type="string" default="1.2" required>
  The API version to use. Supported versions are `1.1` and `1.2`.
</ParamField>

### Request Body Parameters

<ParamField body="birth_date" type="string" required>
  Date of birth of the licence holder. Format: YYYY-MM-DD.
</ParamField>

<ParamField body="given_name" type="string" required>
  The first name of the licence holder.
</ParamField>

<ParamField body="family_name" type="string" required>
  The last name of the licence holder.
</ParamField>

<ParamField body="licence_number" type="string" required>
  The driving licence number to verify.
</ParamField>

<ParamField body="card_number" type="string" required>
  The card number associated with the licence.
</ParamField>

<ParamField body="state_of_issue" type="string" required>
  The state where the licence was issued. Must be one of: NSW, QLD, SA, TAS, VIC, WA, ACT, NT.
</ParamField>

### Response Body

| Field | Type | Description |
|---|---|---|
| `message` | string | A message describing the response status (e.g. "Verification Result"). |
| `data`object | object | The driving licence verification result data. |
| ↳`documentResult` | object | Contains the overall verification result including ActivityId, OriginatingAgencyCode, VerificationRequestNumber, and VerificationResultCode ("Y" for verified, "N" for not verified). |
| ↳`documentDetails` | object | Field-by-field match results. Each field (GivenName, FamilyName, LicenceNumber, CardNumber, BirthDate, StateOfIssue, etc.) will have a value of "Full Match", "Partial Match", or "No Match". |
| ↳`status` | string | Overall verification status. "Y" indicates the document is verified, "N" indicates it is not verified. |

### Response Codes

| Code | Description |
|---|---|
| 200 | The driving licence was successfully verified and the match results are returned. |
| 400 | Bad Request. Missing or invalid parameters. |
| 401 | Unauthorized. Missing or invalid credentials. |
| 500 | Internal Server Error. |
