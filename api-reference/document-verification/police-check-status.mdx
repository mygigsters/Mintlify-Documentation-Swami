---
title: "Police check status"
description: "This endpoint retrieves the current status of a police check application. It returns the applicant's details, processing status, verification status, and the check result from ACIC (Australian Criminal Intelligence Commission)."
api: "POST /status/police-check"
---

### Headers

<ParamField header="X-API-Version" type="string" default="1.2" required>
  The API version to use. Supported versions are `1.1` and `1.2`.
</ParamField>

### Request Body Parameters

<ParamField body="reference_id" type="string" required>
  The reference ID of the police check to retrieve the status for.
</ParamField>

### Response Body

| Field | Type | Description |
|---|---|---|
| `message` | string | A message describing the response status (e.g. "Verification Result"). |
| `data`object | object | The police check details. |
| ↳`id` | number | The unique identifier for the police check. |
| ↳`continue_url` | string | URL for the applicant to continue or resume the police check process. |
| ↳`verify_status` | string | The identity verification status (e.g. "PRIOR", "VERIFIED", "UNVERIFIED"). |
| ↳`status` | string | The current processing status of the check (e.g. "PREP", "SUBMITTED", "COMPLETE"). |
| ↳`first_name` | string | The first name of the applicant. |
| ↳`last_name` | string | The last name of the applicant. |
| ↳`email` | string | The email address of the applicant. |
| ↳`type` | string | The type of check (e.g. "EMPLOYMENT"). |
| ↳`reason` | string | The reason for the police check (e.g. "Driver"). |
| ↳`services` | array | The list of services included in the check (e.g. ["Police"]). |
| ↳`accept_status` | string | Whether the applicant has accepted the terms (e.g. "ACCEPTED", "PENDING"). |
| ↳`result` | string | The check result (e.g. "UNKNOWN", "CLEAR", "DISCLOSABLE"). |
| `result`object | object | A summary of the police check result. |
| ↳`status` | string | The overall result status (e.g. "UNKNOWN", "CLEAR", "DISCLOSABLE"). |
| ↳`message` | string | A human-readable message explaining the current result status. |

### Response Codes

| Code | Description |
|---|---|
| 200 | The police check status was successfully retrieved. |
| 400 | Bad Request. Missing or invalid reference_id. |
| 401 | Unauthorized. Missing or invalid credentials. |
| 500 | Internal Server Error. |

```java Java
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;
import java.util.Base64;

public class Example {
    public static void main(String[] args) throws Exception {
        String credentials = Base64.getEncoder()
            .encodeToString("YOUR_UUID:YOUR_SECRET".getBytes());

        String body = String.join("\n",
            "{",
            "  \"reference_id\": \"14005220\"",
            "}"
        );

        HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create("https://qa-payments.mygigsters.com.au/api/v1/status/police-check"))
            .header("Authorization", "Basic " + credentials)
            .header("X-API-Version", "1.2")
            .header("Content-Type", "application/json")
            .method("POST", HttpRequest.BodyPublishers.ofString(body))
            .build();

        HttpResponse<String> response = HttpClient.newHttpClient()
            .send(request, HttpResponse.BodyHandlers.ofString());

        System.out.println(response.body());
    }
}
```
